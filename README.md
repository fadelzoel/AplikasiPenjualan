# Aplikasi Penjualan (Java Swing)

Aplikasi kasir dan manajemen penjualan berbasis desktop menggunakan Java Swing, SQLite, dan iText PDF.

## Fitur
- Master Barang
- Master Pelanggan
- Transaksi Penjualan
- Cetak Bon (PDF)
- Sistem Lisensi & Trial (Ed25519 Asymmetric Cryptography)

## Cara Menjalankan
1. Buka project di NetBeans.
2. Pastikan semua library di folder `libs` sudah ditambahkan ke Libraries.
3. Jalankan `Main.java`.
